# Certification Plan

Starts after the Capstone (stage 14). The order is based on what DevOps job posts in Egypt and the Gulf ask for, plus cost and effort.

**What the market asks for:** Cairo/Gulf DevOps posts commonly list CKA as preferred, AWS Solutions Architect or SysOps Associate as required for AWS roles, AWS DevOps Professional or Microsoft DevOps Engineer Expert for senior roles, and Terraform as an advantage.

## 1. HashiCorp Terraform Associate (004)
- **Why first:** cheap, quick, and fresh from the capstone. Builds momentum.
- **Format:** ~57 multiple-choice questions, 60 min, online proctored. Tests Terraform 1.12.
- **Fee / validity:** $70.50, no free retake; valid 2 years.
- **Prep:** official HashiCorp learning path + one practice-test set.

## 2. Certified Kubernetes Administrator (CKA)
- **Why:** the most requested Kubernetes certification; a hands-on exam that matches how I learn.
- **Format:** 2-hour performance-based exam, 15–20 command-line tasks.
- **Fee:** $445 list (includes one retake + Killer.sh simulator). The Linux Foundation runs frequent sales, so buy the voucher during one and check how long it stays valid.
- **Prep:** Killer.sh sessions, kubeadm cluster practice, troubleshooting drills.

## 3. AWS Solutions Architect – Associate (SAA-C03)
- **Why:** the AWS cert employers recognize most; required in many AWS DevOps posts.
- **Fee:** $150. Valid 3 years.
- **Note:** do a 1–2 week AWS refresher first (AWS study ends months before this exam).
- **Skipping Cloud Practitioner:** it's aimed at people without IT experience, and SAA covers its content.

## 4. AWS DevOps Engineer – Professional (DOP-C02)
- **Why:** the senior AWS DevOps credential.
- **Fee:** $300. Best taken after some real-world use of the tools.

## Optional, depending on direction
- **Microsoft Agentic DevOps Engineer Expert (AZ-401).** AZ-400 retires 1 Feb 2027; AZ-401 is its replacement (beta as of Oct 2026). AZ-104 should help with prerequisites. Verify the requirements when it's time.
- **SRE path:** Prometheus Certified Associate (PCA).
- **Platform path:** CKAD, or Certified Cloud Native Platform Engineer (CNPE).
